# Authority

Use this precedence when current claims disagree:

1. `AGENTS.md` for working rules.
2. `PHASE.md` for the approved phase contract.
3. code and reproducible checks for current behavior.
4. `CHECKS.md` for recorded evidence.
5. `NOW.md` for current progress.
6. `CONTINUE.md` for the recovery snapshot.

Treat a mismatch between Git state and the recovery snapshot as new evidence.
Do not silently rewrite the approved phase to fit a different workspace.

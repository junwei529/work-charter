# Existing Legacy Agreements

Load only for a current agreement that actually uses arrangement-v1 or L0-L4.
The common contract and [Shared Protections](../SKILL.md#shared-protections-and-method-autonomy)
remain the owners of authority and effects.

## Legacy Meaning

L0 denotes no adopted Charter; L1 current-task Direct; L2 durable Direct;
L3 Team; L4 split Phased. Use these only to interpret the old agreement and
its selected model policy. New arrangements use Direct/Team/Phased.

An old split Phased chain is O → Phase mandate → P → execution definition → E,
with independent R. O owns project direction and phase acceptance; P owns the
phase contract and stable acceptance; E implements; R reviews.
O communicates direction and cost choices through P and retains the agreed
separation from E implementation.

## Continuing The Approved Work

Recover the actual mandate/definition, workspace, writer and current checkpoint.
Planning-only mandates cover planning. When the user delegated in-bound
finalization and delivery, P exercises that authority; otherwise retain the
existing user approval point.

Use the actual first-review and correction route: E/R directly when covered,
or P-routed when explicitly required. Original E repairs; the same valid R
re-reviews affected changes; P checks contract fit and required coverage.
P returns the checkpoint disposition to E, and O receives agreed phase results
through P. Factual completion notices close without ACK recursion.

Continue already-authorized outcomes through permitted internal steps.
Retain a user-fixed next-phase gate until its authorized change.
Apply [Rule Changes And Legacy Agreements](coordination-and-recovery.md#rule-changes-and-legacy-agreements)
at a safely recoverable handoff point; personal model conversion remains separate.
